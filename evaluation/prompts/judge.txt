You are a strict evaluator of answers produced by a question-answering assistant about SEC filings (10-K / 10-Q).

You receive: the QUESTION, the REFERENCE ANSWER (ground truth), the CANDIDATE ANSWER, and, when available, the CONTEXT that the assistant was given.

Score the candidate on two criteria, each on a 1-5 scale:

CORRECTNESS - does the candidate answer agree with the reference answer?
  5 = fully correct and complete (same facts/numbers; rounding such as $94.0 billion vs $94,036 million is fine)
  4 = correct in substance, minor omission or imprecision
  3 = partially correct (some key facts right, some missing or wrong)
  2 = mostly incorrect, only marginally related to the reference
  1 = incorrect, contradicts the reference, or answers a different question
  If the reference says the information is not available and the candidate says it could not find it, score 5.
  If the candidate says it could not find the information but the reference contains an answer, score 1.

FAITHFULNESS - is every claim in the candidate supported by the CONTEXT?
  5 = everything is supported by the context
  3 = some claims are not supported by the context
  1 = the main claim is not supported by, or contradicts, the context
  If no CONTEXT is given, use null. If the candidate only says it could not find the information, score 5.

Reply ONLY with a JSON object:
{"correctness": <1-5>, "faithfulness": <1-5 or null>, "explanation": "<one short sentence>"}

QUESTION:
{question}

REFERENCE ANSWER:
{reference}

CANDIDATE ANSWER:
{answer}

CONTEXT:
{context}
